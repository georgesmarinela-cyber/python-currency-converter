# Simple Python Currency Converter

A lightweight Python script that converts EUR to USD, built to demonstrate core Python fundamentals.

## Features
- Interactive console input
- Type hinting for clear code structure
- Basic input validation and error handling (handling non-numeric inputs and negative values)

## How to Run

1. Make sure you have Python installed.
2. Run the script in your terminal or IDE:
   ```bash
   python currency_converter.py
